# Project Milestones
## Milestone 1 — Domain model and API
Model customers, meters, readings, tariffs and billing periods. Implement a Django/PostgreSQL API that ingests readings and enforces basic constraints.
Components: Python, Django, domain modelling, database design and tests.

## Milestone 2 — Operator investigation UI
Build a simple React interface displaying readings, discrepancies and investigation status. Expose the data through GraphQL.
Components: full-stack delivery, GraphQL, usability and API design.

## Milestone 3 — Reliable background processing
Introduce Celery workers for bill calculation and recalculation. Handle retries, duplicate jobs, partial failures and idempotency.
Components: asynchronous processing, reliability and fault tolerance.

## Milestone 4 — Production engineering
Add structured logs, error tracking, operational metrics, realistic failure scenarios, automated tests and a short incident investigation write-up.
Components: observability, production debugging and engineering judgment.
